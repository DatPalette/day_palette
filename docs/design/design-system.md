# DayPalette 设计系统（Design System）

> 跨移动端与 Web 的共享设计语言，当前已收口到 [`../../../daypalette-docs/design/shared-design-language.md`](../../../daypalette-docs/design/shared-design-language.md)。
> 本文件从当前起主要记录 **HarmonyOS 客户端实现映射**：ArkUI 页面、尺寸、组件形态与像素级补充；若要修改共享品牌气质、排版角色、语义色层或动效节奏，应优先更新顶层共享文档，再回写本文件。

本文档在 [`../mockups/daypalette-premium-mockup.html`](../mockups/daypalette-premium-mockup.html) 与共享设计语言文档的基础上，补充 DayPalette App 的工程令牌与实现细节。HTML 原型仅作像素级对照与疑难细节参考，不必每次改 HTML。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **纸质画廊感** | 大色卡像层叠纸片：轻微 3D 旋转、柔和长阴影，避免扁平贴纸感。 |
| **编辑级排版** | 标题用衬线（Display），界面文案用无衬线（UI）；中英分栈。 |
| **克制的高级感** | 圆角极小（2px 为主）、细边框、低对比分割线；留白充足。 |
| **材质一致** | 顶栏与底栏统一毛玻璃：同色半透明底 + 模糊 + 轻微饱和提升。 |
| **动效有目的** | 主色切换偏慢（0.6s）显“晕染感”；显隐用同一套 cubic-bezier。 |

## 2. 色彩令牌（Color Tokens）

### 2.1 语义色（固定，不随配色盘变化）

| Token | 值 | 用途 |
|-------|-----|------|
| `bg.page` | `#f9f8f6` | 应用主背景（设备内画布）。 |
| `bg.canvas` | `#e5e3df` | 原型中外层展示背景；真机可为系统背景或同系色。 |
| `text.primary` | `#1a1a1a` | 主文案、选中态、实心按钮字色。 |
| `text.muted` | `#8c8c8c` | 次要文案、标签、未选中场合。 |
| `border.subtle` | `rgba(0, 0, 0, 0.08)` | 描边按钮、卡片默认边框、设置列表分隔。 |
| `border.hairline` | `rgba(0, 0, 0, 0.03)` | 顶栏底边、底栏顶边、设置标题下沿。 |
| `surface.card` | `#ffffff` | 配色卡片、设置分组底色。 |
| `overlay.glass` | `rgba(249, 248, 246, 0.75)` | 毛玻璃条背景（与 `bg.page` 同色相）。 |
| `fill.inverse` | `#1a1a1a` | 主按钮背景（等同 `text.primary`）。 |
| `fill.inverse-hover` | `#000000` | 主按钮悬停/按压（Web）；原生可用略深或 opacity。 |
| `text.on-inverse` | `#ffffff` | 主按钮上的字与图标。 |

### 2.2 动态配色（随当前 Palette 变化）

由数据驱动三个 CSS 变量（原生侧应对应 `main / sec / acc` 三色）：

| Token | 原型变量 | 说明 |
|-------|-----------|------|
| `palette.main` | `--c-main` | 主色块，面积最大。 |
| `palette.secondary` | `--c-sec` | 辅色块。 |
| `palette.accent` | `--c-acc` | 点缀色块，面积最小。 |

切换配色时，**三色与标签文案需同一过渡时长与曲线**（见 §7）。

### 2.3 纹理（可选）

- **页面级噪点**：SVG `feTurbulence`，`baseFrequency ≈ 0.65`，`opacity ≈ 0.05`，叠于 `bg.canvas`。
- **色块噪点**：叠在色卡上，`baseFrequency ≈ 0.8`，`opacity ≈ 0.15`，`mix-blend-mode: overlay`（原生需评估性能，可弱化或省略）。

## 3. 字体与排版（Typography）

### 3.1 字体栈

| 角色 | English | 中文（zh） |
|------|---------|------------|
| **Display**（大标题、日期、场合名） | `Cormorant Garamond`（400/600，标题可用 italic） | `Noto Serif SC`（400/600/700） |
| **UI**（正文、按钮、设置） | `DM Sans`（400/500/700） | `Noto Sans SC`（400/500/700） |

中文模式下：Display **不使用 italic**；标题可加 `letter-spacing: 0.05em`。

### 3.2 字号与字重阶梯

| 用途 | 字号 | 字重 | 其他 |
|------|------|------|------|
| 情绪主标题（Mood） | 42px | 600（Display） | 行高 1.1；英文 italic |
| 顶栏日期 | 24px | 600（Display） | `letter-spacing: 0.02em` |
| 区块小标题（SECTION） | 10px | 默认 | 全大写，`letter-spacing: 0.15em`，`text.muted` |
| 场合列表项 | 20px | 默认（Display） | — |
| 配色卡标题 | 13px | 500 | — |
| 配色卡描述 | 11px | 默认 | `text.muted` |
| 色值标签（MAIN/SEC/ACC） | 10px | 标签 500 | 全大写，`letter-spacing: 0.15em`；HEX 用 `text.primary` |
| 底栏按钮 | 13px | 500 | 全大写，`letter-spacing: 0.05em` |
| 设置标题 | 16px | 600 | `letter-spacing: 0.02em` |
| 设置行主文案 | 15px | 默认 | — |
| 设置行次要值 | 14px | 默认 | `text.muted` |
| 语言切换按钮 | 13px | 600 | — |

*注：真机用 `sp/vp` 时按同一比例缩放，保持层级关系即可。*

## 4. 间距与布局（Spacing & Layout）

### 4.1 水平安全区

- 主内容左右内边距：**24px**（顶栏、Hero、场合区、底栏一致）。
- 横向滚动列表：**左侧与内容对齐 24px**，列表右侧预留 **24px** `padding-right`（最后一张卡不贴边）。

### 4.2 垂直节奏（摘自原型）

| 区域 | 关键间距 |
|------|-----------|
| 顶栏 | `padding: 42px 24px 16px`（含状态区占位逻辑时按平台调整） |
| Hero 上内边距 | `10px` 顶，`24px` 水平 |
| 主标题下缘 → 色卡区 | `margin-bottom: 30px` |
| 色卡构图高度 | 容器 **320px**；主块约 **260px** 高 |
| 色值标签 | 构图下方 `margin-top: 8px`，三列等宽分布 |
| 场合区 | 上 `margin-top: 70px`，下 `30px`；区块标题下 `16px` |
| 场合项间距 | `gap: 24px` |
| 精选配色列表 | 卡片 `gap: 16px`；列表内边距 `24px 24px 20px`；区块底 `padding-bottom: 80px`（为滚动留白） |
| 精选动作区 | 列表下方 `padding-top: 20px`，容器左右 `24px`；主动作卡与次动作行间距 `10px` |
| 底栏 | `padding: 16px 24px 32px`；两按钮 `gap: 12px` |

### 4.3 图标按钮

- 圆形图标按钮（设置等）：**36×36px**，圆形，`1px` `border.subtle`。

| 元素 | 半径 |
|------|------|

| Hero 三色主卡 | **16px** |
| 顶栏胶囊微缩预览 | **14px**（高 28px → 胶囊） |
| Hero 微缩预览 | **6px** |
| 设置分组容器 / 选项卡 | **8px** |

| 设备框（仅演示） | 48px / 内层 40px — **真机用屏形+安全区，勿硬编码手机框** |

## 6. 阴影与层次（Elevation）

| 元素 | 参数 |
|------|------|
| 大色卡默认 | `radius 24`, `offsetY 12`, `rgba(0,0,0,0.10)` |
| 胶囊微缩预览 | `0 3px 10px rgba(0,0,0,0.06)` |
| Hero 微缩预览 | 沿用 Hero 卡组阴影比例缩放，不额外加外框 |
| 选中配色卡 | `0 10px 20px rgba(0,0,0,0.03)` |
| 设置分组 | `0 4px 12px rgba(0,0,0,0.02)` |
| 语言选中项 | `0 2px 8px rgba(0,0,0,0.06)` |
| 主按钮 hover（Web） | 略 `translateY(-2px)`；原生可用按压缩放替代 |

### 6.1 色卡 3D 构图（须保留的相对关系）

- 容器 `perspective: 1000px`（或原生等价 3D 变换）。
- **Main**：`240 × 260`，左上锚定，`rotateY(5deg)`。
- **Sec**：`176 × 180`，偏右下，`left: 144`、`top: 120`，`rotateY(-5deg)`。
- **Acc**：`112 × 100`，偏左下前景，`left: 48`、`top: 220`。

以上为当前 ArkUI 实装基准（基准高度 `320`）；缩放型预览必须按同比例换算，保持「主大、辅中、点小」与 z 序一致。

## 7. 动效与交互（Motion）

### 7.1 时长

| 场景 | 时长 |
|------|------|
| 主色 / 色卡 / 标签颜色变化 | **0.6s** |
| 顶栏日期淡出 + 迷你色条淡入 | **0.4s** |
| 设置面板滑入滑出 | **0.4s** |
| 一般 hover、语言切换、场合字色 | **0.2s–0.3s** |
| 整页区块入场（fadeUp） | **0.8s**，阶梯延迟 0.1s / 0.2s |
| 全局 `font-family` 切换 | **0.3s** ease |

### 7.2 曲线

- **标准顺滑（推荐默认）**：`cubic-bezier(0.16, 1, 0.3, 1)` — 用于颜色、顶栏形态、面板位移。
- **一般 ease**：`ease` — 用于次要过渡。

### 7.3 滚动行为

- 主列表：**隐藏滚动条**，`smooth` 滚动（回顶等）。
- **Sticky Mini-Hero**：`scrollTop > 60`（px，原生按 vp 换算）时，顶栏进入 `scrolled`：日期区 `opacity: 0`、`translateY(-10px)`；迷你三色条 `opacity: 1`、`translateY(0)`。点击迷你条 **平滑回顶**。

---

## 8. 毛玻璃（Frosted Bars）

顶栏与底栏统一：

- `backdrop-filter: blur(20px) saturate(150%)`（Web）；ArkUI/SwiftUI 用等价 `backdropBlur` + 材质。
- 背景：`overlay.glass` `rgba(249, 248, 246, 0.75)`。
- `z-index` 高于滚动内容（原型为 **30**）。
- 与圆角容器衔接时，注意顶/底圆角与 `sticky` 防裁切（原型用 **40px** 与内层圆角对齐）。

## 9. 组件规格摘要

### 9.1 TopBar

- 左：**仅日期**（24px Display）；不设占位地点/城市文案；未来若接天气/定位再扩展顶栏信息结构（见 PRD 未来规划）。
- 展开态与收缩态切换：左侧为**同位叠放文本区**，展开时显示日期，收缩时切换为当前 Hero 标题单行；二者共用左侧宽度并以位移 + 透明度切换。
- 顶栏中央保留独立微缩预览插槽，不参与左右排版挤压；仅在滚动超过阈值后显示并可点击回顶。
- 顶栏微缩预览当前实装尺寸为 **150×28**，插槽尺寸 **152×44**。
- 右：设置圆形按钮 36px。

### 9.2 Occasion（场合）

- 横向滚动，无滚动条。
- 未选中：`text.muted`；选中：`text.primary`，下方 **4px** 圆点指示器（**4×4**），距文字 **4px**。

### 9.3 Curated Palette Card

- 最小宽度 **140px**，内边距 **16px**，白底，`border.subtle`，圆角 **2px**。
- 当前实装高度 **96px**，内容为顶部色带 + 下方标题/描述两层文本。
- 顶部三色条：**8px** 高，圆角 **2px**，flex 比例 **3 : 2 : 1**（与 Hero 面积感一致）。
- 选中：边框色为 `text.primary`，加选中阴影（见 §6）。

### 9.4 Palette Actions

- 精选配色列表下方是一组编辑型动作区，而非传统工具栏。
- 第一行是主动作卡“随机”：白底、`2px` 圆角、`1px border.subtle`，内部为左侧标题 + hint，右侧 `76×10` 三色微条与细分隔线。
- 第二行是两个次动作按钮：“沿用昨日”和“精调”，等高 **42px**、等分布局、间距 **10px**。
- “沿用昨日”在无有效昨日快照时应降级为弱化态：更浅背景、更淡边框、整体透明度下降且不可点击。

### 9.5 BottomActions

- 两按钮等高 **52px**，等分 `flex: 1`，图标 **16px**，图标与字 `gap: 8px`。
- **Save**：实心 `fill.inverse`，字 `text.on-inverse`。
- **Share**：透明底，`border.subtle`，字 `text.primary`。

### 9.6 Mini Preview

- 微缩预览有两种样式：`Capsule` 与 `Hero`，均复用当前三色数据，不允许出现第三套独立构图规则。
- 顶栏场景优先轻量化：使用 **150×28** 的窄条版本；设置页场景优先辨识度：使用 **96×40** 的较高版本。
- `Capsule` 维持 `3 : 2 : 1` 的平面比例色条；`Hero` 必须从 Hero 主构图按高度同比缩放，不能手写另一套近似叠片。

### 9.7 Settings Panel

- 全屏覆盖，`translateX(100%)` → `0`，时长 **0.4s**，曲线同 §7.2。
- 头部右侧保留 **36px** 占位，标题居中；左侧返回按钮当前额外保留 `8px` 左内边距以减轻贴边感。
- 外层内容区左右留白 **24px**，分组内边距为左右 **20px**、上下 **16px**。
- 语言切换轨道与预览样式选项卡均使用 **8px** 容器圆角、**6px** 芯片圆角。
- 微缩预览样式选择为并列双卡，每张卡内部上方展示预览、下方展示标签；选中态使用浅底 `surface.subtle`。

### 9.8 语言切换（Segmented）

- 轨道：`rgba(0,0,0,0.04)`，内边距 **2px**，圆角 **8px**。
- 选中项：白底 + 阴影（§6），字色 `text.primary`。

## 10. 无障碍与实现提示

- 可点击区域不小于 **44×44** 时宜在原生侧扩展热区（原型部分按钮为 36px，可接受但建议达标）。
- 颜色对比：正文与背景需满足 WCAG；深色配色盘上的标签依赖 HEX 展示，注意深色模式下若扩展主题需单独令牌表。
- 动效：系统「减少动态效果」开启时应缩短或关闭非必要动画。

---

## 11. 给 AI / 工程师的约束清单

开发**任何**新界面时：

1. 使用 §2 语义色与动态三色模型，不随意新增加灰阶或主色。
2. Display / UI 字体角色与 §3 中英分栈一致。
3. 水平 **24px** 与 §4 间距阶梯为默认；新增区块应对齐该网格。
4. 默认圆角：**2px**；设置、胶囊等仅使用 §5 已列半径。
5. 需要「浮在内容之上」的顶/底栏：必须 §8 毛玻璃三件套（模糊 + 饱和 + 半透明底色）。
6. 涉及 palette 变化：动画 **0.6s** + `cubic-bezier(0.16, 1, 0.3, 1)`。
7. 与原型冲突时：**以原型 HTML 像素为准做一次校准**，然后将差异合并回本文档（保持单一真相演进）。
