# 壁纸工坊方案

## 1. 文档定位

本文用于收敛 DayPalette 基于当前配色生成手机壁纸的产品判断、交互结构、情绪价值方向与最小实现边界。

当前要解决的问题不是“再加一个导出模板”，而是把当前 palette 延展为一份更贴近用户日常桌面的情绪化产物，同时不打散 DayPalette 现有“选场景 -> 选 palette -> 导出 / 分享”的主链路。

---

## 2. 产品判断

### 2.1 功能定位

壁纸能力当前统一定位为：

- 当前配色的周边输出模式

它服务的是“我想把今天这组颜色继续带到手机桌面”的需求，而不是新的一级导航，也不是替代现有 1:1 出图的主能力。

### 2.2 不建议的入口方案

当前不建议：

1. 在首页底部主操作区新增第三个强按钮。
2. 把“壁纸”与“随机选 / 沿用昨日 / 精调”混成同一层编辑动作。
3. 首版直接做成系统级“一键设为壁纸”承诺。

原因：

1. 底部主操作区当前已明确承载保存与分享，不宜继续加重。
2. 壁纸是导出延伸，不是 palette 编辑动作本身。
3. 系统设壁纸链路、裁切规则与权限边界仍需单独验证，首版不应提前承诺。

### 2.3 推荐定位

更合理的处理方式是：

1. 在首页当前配色操作区之后提供一个轻量但可见的入口。
2. 点击后进入单独的全屏“壁纸工坊”。
3. 在工坊内完成样式选择、实时预览、变体切换与保存。

---

## 3. 入口与主流程

### 3.1 推荐名称

任务与文档统一称为：

- 壁纸工坊

英文可用：

- Wallpaper Studio

### 3.2 推荐入口位置

推荐入口位置：

1. 首页 `PaletteSelector` 动作区之后。
2. 位于底部保存 / 分享栏之上。

推荐原因：

1. 它和当前 palette 操作链路相邻，语义自然。
2. 不占用底部主操作层级。
3. 用户会理解为“在确定当前 palette 后，可进一步生成桌面产物”。

### 3.3 推荐主流程

1. 用户在首页确认当前 palette。
2. 点击“生成壁纸”或等价文案入口。
3. 进入壁纸工坊，默认使用当前三色生成首个预览。
4. 用户横滑切换样式卡，必要时点击“换一版”查看同款变体。
5. 用户查看当前设备比例预览，可在“纯净预览 / 锁屏想象”间切换。
6. 点击“保存壁纸”写入相册。
7. 保存成功后，提示用户可到系统相册中设为壁纸。

首版不建议：

1. 进入独立多级导航。
2. 在工坊内暴露大量自由参数。
3. 直接承诺分享与保存以外的系统集成能力。

---

## 4. 页面结构与状态

### 4.1 页面层级

推荐结构：

1. 顶部栏：关闭、标题、可选的“保存”次入口。
2. 预览区：按当前设备比例展示壁纸。
3. 预览模式切换：纯净预览 / 锁屏想象。
4. 样式区：横向样式卡片列表。
5. 变体与说明区：一句情绪文案 + “换一版”。
6. 底部主按钮：保存壁纸。

### 4.2 预览原则

预览区必须遵守：

1. 默认按当前设备纵向比例渲染，而不是沿用 1:1 出图比例。
2. 预览优先展示真实视觉重心，而不是纯技术缩略图。
3. 锁屏想象层只作为叠层预览，不实际烧录到导出图片里。

### 4.3 至少定义的状态

首版至少要有以下状态：

1. 默认进入：基于当前 palette 自动生成首个样式。
2. 切换样式：主预览平滑切换到另一款构图。
3. 切换变体：同一款样式下调整角度、拼块比例或渐变重心。
4. 保存中：按钮进入加载态，避免重复保存。
5. 保存成功：出现短 toast，并保留当前预览。
6. 保存失败：提示失败原因，并允许重试。

### 4.4 首版交互边界

首版不建议提供：

1. 手动拖拽渐变锚点。
2. 自定义文字贴纸或复杂排版。
3. 与桌面图标遮挡相关的高级排版编辑器。

首版更适合：

1. 用固定但精心设计的样式模板提供策展感。
2. 用少量离散变体替代完全自由编辑。

## 5. 样式体系建议

### 5.1 首版建议的 4 类基础样式

1. 三色拼合 · 纵向分区
2. 纸片拼贴 · 错位层叠
3. 三色渐变 · 线性流动
4. 柔雾渐变 · 空气晕染

说明：

1. 前两类偏结构化，适合更克制、编辑感更强的风格。
2. 后两类偏情绪化，适合柔和与氛围导向的用户。

### 5.2 每类样式的变体建议

每类样式首版建议至少提供 3 个自动变体。

变体来源建议：

1. 拼合类：比例、重心、错位方向。
2. 渐变类：角度、扩散半径、颜色主次重心。

原则：

1. 变体必须是“策展后的差异”，不能像随机数扰动。
2. 用户点击“换一版”时，感知应是“同一气质下的另一张好版本”。

### 5.3 安全区建议

所有样式都应预留桌面安全区意识：

1. 顶部不要放过强对比边界，避免压住锁屏时间后显得碎。
2. 中下区域避免过密细碎结构，减少与桌面图标产生视觉打架。
3. 渐变亮部与暗部不要极端贴边，避免系统裁切后失衡。

---

## 6. 情绪价值方向

壁纸能力不应只提供“导出一张图”，而应提供一种“今天这组颜色已经陪我上桌面了”的完成感。

### 6.1 推荐的情绪增强点

1. 每张样式使用具气质的名字，而不是“模板 1 / 模板 2”。
2. 每次预览配一条极短的策展式情绪文案。
3. 提供可选的“微签名”开关，默认关闭。
4. 提供锁屏想象层，帮助用户在保存前先感受上桌面的样子。
5. 把壁纸和今日分享图理解为同一日主题下的两种产物。

### 6.2 文案风格要求

文案应偏：

1. 杂志感
2. 克制
3. 有情绪但不过度煽情

不建议：

1. 口号式鸡汤
2. 过度功能化提示
3. 明显模板编号语言

### 6.3 可试的文案方向

可参考的语气：

1. 今天的桌面，适合更轻一点。
2. 把这组颜色留给今天。
3. 这一版更安静，也更贴近你现在的状态。

---

## 7. 实现边界

### 7.1 与现有导出系统的关系

当前不建议把壁纸直接并入现有 `templateId` 的 1:1 出图模板系统。

更合理的边界是：

1. 继续保留当前 1:1 色卡出图链路不变。
2. 为壁纸新增独立的样式标识与渲染入口。
3. 仅复用当前三色快照、颜色工具与保存链路。

### 7.2 数据与状态建议

首版建议：

1. 进入壁纸工坊时先拍一份当前 palette 快照。
2. 工坊内部的样式与变体状态优先做页面临时状态。
3. 不默认写入 `TodayOutfitState` 主实体，除非后续验证用户有明确“记住上次壁纸样式”的需求。

### 7.3 导出边界

首版导出应满足：

1. 输出尺寸以当前设备像素尺寸为准。
2. 保存到相册的产物不包含锁屏想象层的假时间和假状态栏。
3. 首版主打“保存壁纸”，分享能力可后续复用，但不作为阻塞首发能力。

### 7.4 商业边界

当前建议：

1. 基础样式全部免费。
2. 高级渐变、动态壁纸或更多风格包保留为后续 Pro 扩展讨论项。
3. 不在首版壁纸工坊内引入新的付费打断。

## 8. Iteration-05 最小实现切片

### BL-BR-09A · 产品与文档定稿

1. 回流 PRD、Backlog、Iteration-05。
2. 明确入口、主流程、样式边界与商业边界。

### BL-BR-09B · 壁纸工坊 UI 骨架

1. 首页增加壁纸入口卡。
2. 新增壁纸工坊页或全屏浮层。
3. 完成设备比例预览、样式横滑和保存按钮骨架。

### BL-BR-09C · 独立渲染链路

1. 新增壁纸快照结构。
2. 新增壁纸样式枚举与渲染器。
3. 支持当前设备尺寸输出，而不是复用 1080x1080。

### BL-BR-09D · 情绪化包装与收尾

1. 补样式命名与情绪文案。
2. 补保存成功 / 失败反馈。
3. 完成首版样式验收与安全区走查。

---

## 9. 当前结论

当前最合适的推进方式是：

1. 先以“壁纸工坊”作为独立的周边输出能力进入 Iteration-05。
2. 首版聚焦基础静态壁纸，不把系统设壁纸和高级付费样式绑进同一轮。
3. 先把“当前配色 -> 当前设备尺寸壁纸 -> 保存到相册”跑通，再决定是否扩展到更重的商业化与系统集成能力。
