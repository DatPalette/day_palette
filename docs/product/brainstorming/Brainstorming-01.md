# 头脑风暴 01

## 已拍板方向（与 PRD 对齐）

1. **随机 / 精调 / 昨日 的显见性**  
   **保存、分享**：位置与现有视觉层级**保持不变**。  
   **随机、精调、昨日**：不挪到底栏替代保存/分享，而是在**当前布局下提高这三处入口的视觉权重**（尺寸、对比、分组或标签等，具体落地对齐 `docs/design/design-system.md` 与 PRD 今日页）。

2. **精调演进**  
   采用 **「智能配」+ 仍可展开完整微调**：默认或主路径上提供「选主色 → 算法补全和谐 secondary/accent」；用户**始终可展开**对单格/全格的精细调整，与 PRD「微调某一格」一致，不互相替代。

3. **随机能力边界与表述**  
   **Pass**：非预置、算法「随机生成」整套配色。  
   **保留**：从预置/安全集内 **随机选一套**。产品内将「随机」相关文案优化为 **「随机选」**（或等价清晰说法），避免用户理解为「凭空生成」；若有副文案，可简短说明「从推荐套组中随机换一套」之类（以 i18n 与界面空间为准）。

## 其他方向备忘（未拆任务或远期）

- **产品定位**：配色盘为核心，给穿搭灵感，**辅助穿搭配色**，不替代专业设计工具。  
- **周边能力（壁纸）**：由当前配色生成非渐变 / 渐变壁纸，高级渐变可作 IAP；与核心今日配色流程解耦，单独排期。  
- **保存 / 分享产物**：色卡版式偏单一，后续可做更好看、可传播的模板（免费基础模板边界以 PRD 为准）。  
- **Hero / 顶栏微缩**：Hero 三色块形态可再设计；顶栏微缩与配色盘语言一致、提升精致度与可读性。  
- **预置与场景**：补充更贴真实穿搭的套组，场合维度可扩；长期量级目标百套以上，与运营节奏分期。  
- **运营**：配色数据托管与更新流程；调研华为侧免费/低成本内容管理或分发方案，与架构文档对齐选型。

## 附录：原始条目（编号备忘）

1. 明确该产品定位，提供配色盘，主要提供给用户一个灵感，辅助用户进行穿搭配色  
2. 开辟一个周边功能，根据配色生成非渐变壁纸 和 渐变壁纸，渐变壁纸分为普通渐变壁纸，和 高级渐变壁纸（作为 IAP 功能）  
3. 目前随机，精调，昨日等操作 很小，保存 和 分享的按钮却很明显。我的想法是，随机，精调，昨日等操作 很小 为主要操作，保存分享为次要操作？  
4. 保存 分享 色卡产物目前很单一，如何能做到好看优美一些？  
5. Hero 界面目前三个正方形，能不能变化一下形状？有没有什么更高级且优美的呈现方案  
6. 我接下来同时也要作为 app 的运营人员，将后来这些配色方案的数据如何管理。华为有没有免费的内容管理方案？  
7. 随机功能，目前就是随机一套已有的，这确切的说应该是「随机选」。有没有可能 随机出一套非预置的？我们目前有算法支撑吗？  
8. 预置的配色方案，少且不太实用，或者不太现实，可以保留，但是需要增加更贴合现实的方案。与之相关的，场景也可以多一点。预置的方案，总共起码要有百套以上才行。  
9. 精调弹窗的界面太简单了，而且太自由，用户搭配出来的颜色不一定符合配色美学，需要一定的约束，比如只让用户选择一个主色，我们帮用户利用色彩搭配算法完成搭配？我知道这个是要规划一个单独的迭代来做，但是目前只是提出一个想法。  
10. 微缩胶囊展现形态可以跟配色盘一致，不必是胶囊形态，主要是现在顶部 Bar 中呈现出来的是一坨，不太精美
