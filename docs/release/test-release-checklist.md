# 测试与上架检查清单 · DayPalette

> 合并「测试计划」与「发布计划」中最个人开发者必要的条目。

## 1. 开发期：模拟免费 / Pro

在 **Debug** 构建启用隐藏入口（如长按关于 Logo、连点版本号）：

| 模式 | 预期 |
|------|------|
| **强制免费** | `isPro === false`，仅免费套组与默认 Form 皮肤 |
| **强制 Pro** | `isPro === true`，高级套组与付费皮肤可选，**无需真实支付** |
| **真实 IAP** | 联调华为 **沙箱账号**（以 AppGallery Connect 文档为准） |

**要求**：业务代码只从 **单一 Entitlement 源** 读 `isPro`，避免 UI 与数据不一致。

## 2. 功能冒烟（每次发版前）

- [ ] 选场合 → 推荐色变化合理  
- [ ] 套组横滑 → 主预览与缩略图 **比例一致**  
- [ ] 微调单格 → 保存后 Form **刷新**正确  
- [ ] 出图：免费模板 **全部**可用，无 Pro 拦截  
- [ ] 分享、保存相册权限路径正常  
- [ ] Form 点击进今日页  
- [ ] 系统深色模式下 **壳**正确；**三色仍为真实 HEX**

## 3. IAP 与账号

- [ ] 沙箱购买 Pro → 皮肤与高级套组解锁  
- [ ] 杀进程重进 → 权益仍在  
- [ ] **恢复购买** 成功（卸载重装或换机场景按平台能力测）  
- [ ] 商店文案与 App 内 **Pro 说明** 一致（列清含哪些皮肤/配色包）

## 4. 提审前

- [ ] 移除或编译剔除 Debug 强制 Pro 入口  
- [ ] 无测试账号密码硬编码入库  
- [ ] 隐私政策链接（若上架要求）与权限声明一致  
- [ ] 无广告 SDK（本产品策略为无广告）

## 5. 商店素材（与规划 7.6 一致）

- [ ] 截图含：**中卡桌面** + **主应用今日** + **一张分享出图**  
- [ ] 应用名：**今日配色**；英文：**DayPalette**（与商店字段一致）
