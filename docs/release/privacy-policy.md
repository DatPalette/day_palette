# DayPalette 隐私政策

> 更新日期：2026-04-07

## 1. 适用范围

本隐私政策适用于「DayPalette / 今日配色」应用当前版本。

## 2. 我们收集什么信息

当前版本默认**不建立账号体系**，也**不提供自有云同步**。应用的主要数据（如今日配色、场合、导出版式、界面偏好设置）默认仅保存在用户设备本地。

当前版本不主动收集以下信息：

- 手机号、邮箱、身份证号等身份信息
- 联系人、短信、通话记录
- 精确定位信息
- 自建云端用户画像或行为分析数据

## 3. 我们为什么需要权限

当前版本仅在明确需要时申请与功能直接相关的系统权限。

### 3.1 相册 / 图片写入权限

应用在用户主动执行以下动作时，可能请求系统图片写入相关权限：

- 保存当前配色图片到系统相册
- 通过系统分享能力导出当前配色图片

该权限仅用于完成用户主动发起的保存或分享操作，不会在后台静默写入无关内容。

如果用户拒绝授权：

- 应用不会反复无提示申请权限
- 对应保存能力可能不可用
- 其它不依赖该权限的浏览、选色、切换场合等功能仍可继续使用

## 4. 本地数据如何处理

当前版本会在设备本地保存以下信息，以支持核心功能：

- 今日配色状态
- 昨日快照
- 当前场合与所选配色
- 导出版式偏好
- 语言、减少动效、轻微颗粒、微缩预览样式等界面偏好

这些数据用于：

- 恢复用户上次的使用状态
- 支持桌面卡片与应用主界面保持一致
- 支持导出与分享时生成对应图片

## 5. 第三方服务与系统能力

当前版本主要使用 HarmonyOS 系统能力完成以下功能：

- 图片保存到系统相册
- 系统分享面板
- 桌面服务卡片（Form）

当前版本**不接入广告 SDK**。

如后续版本接入商业化、支付、统计或其它第三方服务，我们会在功能上线前同步更新本隐私政策与相关说明。

## 6. 未成年人保护

如你是未成年人，建议在监护人陪同下使用本应用，并在监护人指导下阅读本隐私政策。

## 7. 政策更新

当应用功能、权限使用范围或数据处理方式发生实质变化时，我们会更新本隐私政策。

## 8. 联系方式

如你对本隐私政策有疑问，可通过应用发布页或开发者对外联系方式进行反馈。
